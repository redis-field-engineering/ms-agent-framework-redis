= Packages and compatibility

All five packages share preview version `{preview-version}`, declared in {source-url}/src/Directory.Build.props[`src/Directory.Build.props`].
Preview APIs may change before a stable release.

[cols="2,3",options="header"]
|===
|Package |Purpose
|`Redis.Iris.AgentFramework` |Microsoft Agent Framework history, recall, and Context Retriever providers; depends on the next three packages.
|`Redis.Iris.AgentMemory` |Standalone HTTP client for session events, summaries, filtered memory search, and scoped deletion.
|`Redis.Iris.ContextRetriever` |Authorized MCP tool discovery and invocation, typed reads, and connection caching.
|`Redis.Iris.ContextRetriever.Modeling` |Compile POCO attributes or fluent configuration into a DataModel and compare model changes.
|`Redis.Iris.ContextRetriever.Management` |Optional administrative HTTP client for creating, reading, and updating surfaces. Add it explicitly in deployment tooling.
|===

== Supported baselines

[cols="1,3",options="header"]
|===
|Component |Baseline
|Build SDK |.NET 10, selected by {source-url}/global.json[`global.json`] and required for `.slnx`.
|Library target |`net8.0`; consumable from .NET 10 applications.
|Application runtime |.NET 10 LTS recommended. .NET 8 compatibility is tested until its November 10, 2026 end of support.
|Microsoft Agent Framework |1.23.x; the connector uses 1.23.0.
|Redis Agent Memory |Original `/v1/stores` API (default), or current self-managed Iris API with `ApiMode = AgentMemoryApiMode.Iris`.
|Redis Context Retriever |Managed MCP or self-managed 0.4.2 over loopback.
|===

== Build packages from source

Run from the repository root:

[source,bash]
----
./eng/pack.sh
----

Use `artifacts/packages` as a local NuGet source and keep NuGet.org enabled for external dependencies.
See the xref:quickstart.adoc[quickstart] for installation and the {source-url}/eng/README.md[packaging guide] for release validation.

== Migrate earlier previews

Replace references and namespaces named `Microsoft.Agents.AI.Redis.Iris` with `Redis.Iris.AgentFramework`.
The assembly is `Redis.Iris.AgentFramework.dll`; rebuild applications and restart notebook kernels.
No compatibility assembly is supplied under the earlier name.

Surface administration uses `Redis.Iris.ContextRetriever.Management` rather than the earlier `ContextCtlSurfaceDeployer` API.
See xref:context-retriever-modeling.adoc#review-and-deploy[modeling and management] for the direct HTTP workflow.
