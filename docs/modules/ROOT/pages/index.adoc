:description: Durable agent history, owner-scoped memory, and authorized business context for Microsoft Agent Framework.

Give your agents conversation history that survives restarts, memory that carries across sessions, and tools for retrieving current business records.

The Redis Iris .NET connectors integrate Redis Agent Memory and Context Retriever with Microsoft Agent Framework.
Use the standalone clients in other .NET applications, or attach the providers to an existing model-backed agent.

== Before you start

You need an existing Redis Agent Memory store or Context Retriever surface for the connector you use.
An ordinary Redis server alone does not expose these APIs; service provisioning is separate from these libraries.
See the https://redis.io/docs/latest/develop/ai/context-engine/[Redis Iris documentation] for deployment options.

The packages are maintained by Redis Field Engineering and are not Microsoft products.
All seven packages share version `{preview-version}`; a version in source does not imply publication to NuGet.
Read xref:packages.adoc[compatibility], the xref:security.adoc[security model], and the xref:operational-contract.adoc[preview operational contract] before using customer data.
